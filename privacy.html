Privacy Policy

Last updated: November 16, 2026

Who uses this app

Claude Gmail is a private tool used only by its owner, with the owner's own Google accounts. It is not offered to anyone else.

What data it accesses

With the owner's permission, the app uses the Gmail API to read message metadata (sender, subject, date, size, labels), change labels, move messages to Trash, and manage Gmail filters.

How data is stored and shared

Data is processed on the owner's own computer. Access tokens are stored only on that computer. Mail data is not sold, not used for advertising, and not shared with third parties.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also removes the app's access.

隱私權政策（摘要）

本工具僅供擁有者本人管理自己的 Gmail 帳號使用。資料只在擁有者的電腦上處理，存取權杖只存在該電腦中，不會出售、不會用於廣告，也不會提供給任何第三方。可隨時在 Google 帳戶的「第三方應用程式」頁面撤銷存取權。
